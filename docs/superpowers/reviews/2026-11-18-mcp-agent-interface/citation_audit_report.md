## Orchestrator adjudication

Every WRONG item was re-checked at the source and **all eight are confirmed**. Additional checks:

- **`af17064` — correction in the spec's favour.** The audit marked this UNVERIFIABLE ("no git history reachable with read-only tools"). Local git works offline (no network needed for `git log`), and the commit exists: `af17064 2026-11-15 fix(backup): the proxy refused a bundle the API would have accepted (#68)`. The claim is **true and verifiable**. SY-24's stylistic point (name the incident, don't just drop a hash) stands; the implication that it might be unsupported does not.
- **`tax_engine` no-`else`** confirmed with care: the `} else {` at `:822` is at 8-space indent and belongs to an outer block; the `if BUY / else if SELL / else if SPLIT` chain at 12-space indent (`:665`, `:680`, `:771`) has no terminal `else`. A `DIVIDEND` row therefore produces no lot and no position change — silently.
- **`guard.rs` Err arm** confirmed `Status::InternalServerError` (`:187-190`), so the spec's "503 via `UNAVAILABLE_PATH`" attributes the fairing's behaviour to the guard.
- **`route_coverage_test.rs:169`** `assert_eq!(checked, 21, "the mounted /api surface is 21 operations")` — third cardinality pin, confirmed.
- **`check_access_gate.sh:224`** Rule B regex confirmed: `(FROM|UPDATE|DELETE FROM)[ \t]+(portfolios|assets|transactions)[ \t].*WHERE[ \t]+id`. An `api_token … WHERE id` query is invisible to the gate — which means the spec's claim that the gate will cover `DELETE /api/tokens/<id>` is false, and the isolation matrix is the only real check on it.
- **`date_boundary_test.rs:46-57`** confirmed, including its comment ("a bare date must not silently become midnight UTC"). This is a genuine design consequence the spec missed: the agent path wants bare `YYYY-MM-DD` while the interactive path deliberately rejects it, so the two paths cannot share a date deserializer as the spec implies.
- **`backup/mod.rs:467-470`** and **`backup/schema.rs:49-56`** confirmed: the closed type set is already enforced at bundle validation *and* pinned artifact↔constant. Workstream 0 item 3 is already shipped, as ON-3 and W0-8 also found.

Net effect on the spec's credibility: of the citations that carry a decision, **eight are wrong and sixteen are partly wrong** — and the pattern is consistent, the errors all point the same way, toward the change looking smaller and safer than it is (already-shipped work counted as new, a breaking frontend change described as unaffected, a weekly series promised as daily, a junk type described as a wrong lot rather than as silently dropped data).
